## Read this before reusing any of them

These files describe **the live design systems of real companies**. Using one privately as a
reference is ordinary practice. Reproducing a named brand's identity on a commercial page is not —
and several of these are distinctive enough that the line is easy to cross without noticing.

**IBM Carbon is the deliberate exception, and it is part of why we picked it.** Carbon is genuinely
open source (Apache&nbsp;2.0) and built to be adopted by anyone, so building on it is legitimate
rather than borrowed. IBM Plex is under the SIL Open Font License.

Take palettes, structural ideas and typographic strategy from the runners-up. Do not take
wordmarks, proprietary typefaces or signature shapes.

## Also worth knowing

These files follow Google Stitch's `DESIGN.md` spec — frontmatter tokens, then prose sections for
atmosphere, colour, type, components, layout, depth, constraints, responsive behaviour, and agent
prompts. That structure is why an AI agent can read one and produce matching UI, and it is the
structure the root `DESIGN.md` loosely follows.
